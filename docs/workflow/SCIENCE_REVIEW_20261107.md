## 1. 架构依据、观测半径与质量误差

采用“输入各层质量和热结构 → 原生静力结构求解 → 得到Rmodel → 外部比较观测”的构造是合理的正向建模架构。[MAGRATHEA原论文](https://arxiv.org/abs/2201.03094)说明通过shooting-to-fitting-point求半径；[原项目运行说明](https://magrathea.readthedocs.io/en/latest/user-guide/run-modes.html)也区分正向模型和组成搜索。[GASTLI官方检索教程](https://gastli.readthedocs.io/en/latest/retrieval.html)公开展示composition×mass×thermal参数网格、网格插值，以及M/R/age联合比较。GASTLI原论文的标称质量范围17ME以上，不能当8ME目标的直接物理验证，仅借用统计/网格组织方法。[ExoPlex](https://github.com/CaymanUnterborn/ExoPlex)也可参考分层结构与材料一致性，但不直接替代现有外部TP/HHe模型。

本项目workflow/pilot_grid.py:124的config_text输出mode0和四层质量，没有输入观测目标半径；src/main.cpp:494调用fitting_method的参数也没有Robs。experiments/pure-fe-pilot-20261106/run_pilot.py:143在模型返回后计算Rmodel−2.39。因此原生“半径求根”匹配的是模型内部边界，不是把观测半径写回输出。

纯铁、水、气分数和为1，暂用u=Fe/(Fe+water)、g=f_gas：
f_Fe=(1−g)u；f_water=(1−g)(1−u)；f_gas=g；f_Si=0。
u不是全行星铁分数，绘图须转换；本版没有硅酸盐地幔。“水”指H2O成分，不保证液态。外部TP只控制气层，铁/水沿现有EOS热结构，属于给定热情景的分层模型，不是自洽辐射对流/冷却模型。对照观测还需锁定参考压力和实际TP来源，工程通过不等于这些物理假设已成立。

M误差可以在一次整体grid任务内加入：把Rmodel(u,log g)扩成Rmodel(M,u,log g)，每个M仍须求解或经验证插值；不是把固定M的一次前向输出改个误差条。最小探索可用7.56、8.04、8.54ME三质量切片，但三点仅做初探，必须加中间验证/覆盖检查才可声称传播充分；正式后验还可能需要超过边际68.3%范围的质量尾部。

画“满足M/R区间”的面积与画“68%后验可信面积”是不同统计定义：
- 区间投影：保留在批准质量区间内至少存在一个M，使Rmodel进入批准R区间的组成。所得区域是条件可行域，不自带68%联合概率。
- 后验：对M等未知量积分，p(u,g|D)∝∫ L[D|M,Rmodel(M,u,g)] π(M,u,g)dM。若先临时近似独立高斯，logL=−1/2[(M−Mobs)^2/σM²+(Rmodel−Robs)^2/σR²]；这里只是近似示意，不能把边际posterior的误差自动当原始likelihood。应优先取得联合观测样本/likelihood，保留非对称误差，记录原观测先验及相关性未知状态；使用两个边际需声明近似并做相关性敏感性。logg等距采样不自动等于均匀g先验，网格积分必须有单元体积/先验权重，避免重复计入M观测权重。

[Bonfanti2024 Table5](https://doi.org/10.1051/0004-6361/202348180)的上下误差是68.3%边际posterior区间。[TOI-270 d参考图4/§3.1](https://arxiv.org/html/2511.16722v1)同时考虑M与R误差且对比纯Fe和Earth-like核；其阴影不能直接贴到我们只变R的24点测试上。

## 2. 平均密度初始半径与TP上边界

src/hydro.cpp:1879–1888按各层体积估Rguess≈[3Σ(Mi/rhoi)/(4π)]^(1/3)，气体密度含原生经验修正；1893取0.8/1.2Rguess括区。1904的gsl_root_fsolver_set立即评价端点，R_hydro:1797起构建试探模型并向内积分，derivs_m2:102再按积分压力查TP。平均密度只是初始猜测，不给最终R/P/T，也不保证试探过程都在TP域内。

8例失败查询约1e10+0.00012 dyn/cm²；上限1e10 dyn/cm²=1e9Pa=10000bar；相对仅约1.2e−14。失败在初始括区试探，不能当最终解的气层底压。shots计数到成功构造结尾hydro.cpp:649才增加，因此0shots不表示未发生内部积分。

只读源码发现可能相关的不协调：tp_stepper.cpp:58允许64epsilon级结点偏差，85–98/228–244做snap；但GSL步的中间RHS先进入tp_profile.cpp:154–158严格域检查，可能在后置snap前就失败。这是具体待回归路径，尚无完整中间stage轨迹确认8例均由其引起。下一步先做端点/中间stage和真实越界对照回归；若修复只针对浮点端点等价，须保留真正域外输入的失败，不可随意clamp或延长TP来消除报错。

## 3. “通过点落在半径比较区间”是什么意思

这是两个独立筛选：
1. 数值通过：程序完成、状态/边界拼接/EOS查询/TP域等检查满足冻结条件；
2. 观测比较：在固定M8.04ME及示范TP/P0条件下，2.28≤Rmodel≤2.49RE。

16个数值通过网格点中3个满足第2项。最近直接样本Fe29.97%、水69.93%、气0.10%，Rmodel2.3735947618RE，ΔR=−0.0164052382RE。它只是这16个通过样本中最近，不是全局最优。8个失败为未知，不算观测排除。3点不能定义面积；固定M的边际R区间也不能称联合M/R的68%可信区域。

## 4. 网格改进建议（未实施）

建议“粗覆盖 → 边界自适应加密 → 独立验证 → 统计投影/积分”，目标是整片兼容域：
1. 使用(u,logg,M)，先全域粗覆盖并保留无水边界；极小气量、纯组分边缘和无气g=0必须单列，log轴不能表示0。
2. 每个单元检查R区间/似然阈值是否可能穿过、曲率、相态变化和失败邻域；不能只在中心残差最小点附近加密，也不能仅因角点同号就排除内部狭小分支。加入中点抽查/保守误差界来发现非单调/孤岛；没有证明时有限网格不能保证全局完备。
3. 在已核实连续且有符号括区的局部切片上，分别追Rlower、Rcenter、Rupper等值线；[Brent方法](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.brentq.html)要求可评价连续函数和端点异号。跨失败点或相切但不变号的区域不能直接套括区求根。
4. 残差斜率∂R/∂logg可预测新点，局部带宽约Δlogg≈ΔR/|∂R/∂logg|；只是局部线性估计。斜率近0、曲率大、相变/分支处加密并保留括区保护，避免牛顿法跳错支。外部u和M方向也要检查带形变化。
5. 不同M切片共同投影可形成区间可行域；要概率面积则用质量边缘化和先验/网格体积权重，收敛比较面积边界/概率质量，而非只比较best point。TP/EOS假设变化另分情景，不能混称观测误差。
6. 模型缓存用源码、EOS表、组成、M、TP、边界和容差身份键；插值仅在经验证有效单元内，失败区域留洞。保留真solver独立检查点，要求插值误差小于预先分配的误差预算；不从旧31次余额自动追加科学运行。

以包围质量m积分：
dr/dm=1/(4πr²ρ)，dP/dm=−Gm/(4πr⁴)，dT/dm=(dT/dP)(dP/dm)。
外向内用Mtot−m为自变量，符号相应反转。材料界面保持m/r/P连续，本轮Tgap=0故T也连续；换新物质/相的EOS后密度可跳，dr/dm和温度梯度也可跳。应检查每侧ρ=EOS_side(P,T)，而不是强迫Fe和水的ρ相同。组成边界定位、跳过零质量地幔及GSL重置见hydro.cpp:1022、1175–1199。气层外部TP梯度不再叠加气体内部绝热梯度。

没有独立重推全部Fe/水物理EOS和相平衡，也未完成所有界面局部微分残差/覆盖所有组成的证明。另发现hydro.cpp:982–990等分支先Phase->getthermal()后if(!Phase)，无可用相时可能空指针崩溃；当前通过案例未触发，未证实与8例TP失败有关。应另做“无相→受控失败”的回归再改检查顺序。本轮未修复该缺陷。
